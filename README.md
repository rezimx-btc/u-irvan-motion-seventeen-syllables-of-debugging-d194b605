# Seventeen Syllables of Debugging

One original haiku about debugging, in the 5-7-5 syllable shape. A breakpoint holds its breath while the log line scrolls past midnight — and the last line reframes the hunt: the bug wore the debugger's own face.

> Breakpoint holds its breath
> the log line scrolls past midnight
> the bug wore my face

The program is a tiny stdlib-only Python script: it writes the haiku to `/output/entry.txt` and prints it to stdout.

## Run it

```sh
python3 main.py
```
